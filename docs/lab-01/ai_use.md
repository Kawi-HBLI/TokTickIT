## Reflection
Throughout Lab 1, I learned that being specific with AI prompts produces much better results — telling it exactly which files to modify, which tests to run, and what patterns to follow. The Docker setup decision early on (Issue 1) saved time later because everyone on the team had the same DB environment. The biggest technical takeaway was understanding the full-stack flow: Prisma schema → migration → seed → Express route → React fetch → UI render. Each layer depends on the one below it, so Issue 4 couldn't work until Issue 3's Category model was merged. I also learned that writing tests alongside features (not after) is much more efficient. The mock-based client tests are especially useful because they test UI behavior independently of the backend. One thing I'd do differently next time is set up the PR review process earlier — we could have parallelized Issue 2 and 3 more effectively.
